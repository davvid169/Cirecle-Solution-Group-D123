# Web Development Project - Docker container definition

Welcome to the Web Development project Docker Repository. This repository can supply you
with a Docker container just for the web development project. By creating a new Docker
container for the project there is no interference with the Web Development classes (the
ones focused on learning PHP, HTML & CSS).

**Important**
>You only need these files if you are using the PHP programming language.

Chances are you already have a project setup, including your own GIT repository linked. Therefore,
do not use `git clone` to grab the files. Just download these files (using the GitHub `download zip`) 
and unpack on your harddisk, e.g. in the folder `c:\sources\webdev\project`.

Copy the files to your project and put your project files in the folder `src`.
